# AsciiDoc Preview – glossary

The terms of this plugin and of Orca's plugin host, as the code and docs use them.

## Language

**Frame**:
The sandboxed `<iframe sandbox="allow-scripts">` in which Orca runs a custom editor. It has a strict CSP: no network, no `eval`, no WebAssembly, no file system.
_Avoid_: window, webview, sandbox (the sandbox is the frame's property)

**Entry**:
`editor/index.html`, the single self-contained page Orca loads into the frame. Generated by `scripts/build.mjs`; never edited by hand.
_Avoid_: bundle (a bundle is one part inside it), output

**Payload**:
A compressed, base64-encoded script embedded in the entry in an inert `<script type="application/x-payload">` block and executed on first use (`src/payloads.ts`). The PlantUML engine, Mermaid, Graphviz, highlight.js, KaTeX and each stdlib bundle are payloads.
_Avoid_: chunk, lazy module

**Bootstrap**:
The only uncompressed script in the entry (`src/bootstrap.ts`). It inflates the gzip-compressed app payload and runs it.

**Stdlib bundle**:
One PlantUML standard library (for example `c4`, `azure`) vendored gzipped in `vendor/plantuml-stdlib/` and embedded as a payload. The list is in `scripts/stdlib-list.mjs`.
_Avoid_: library pack, include set

**Not bundled**:
A PlantUML `!include <lib/...>` for a library that is not a stdlib bundle. The preview shows an error box naming the bundled libraries instead of PlantUML's generic message.

**Diagram block**:
A `[plantuml]`, `[mermaid]` or `[graphviz]` block in the AsciiDoc source, written the asciidoctor-diagram way. It becomes a placeholder first and is rendered afterwards.
_Avoid_: diagram macro

**Placeholder**:
What the preview shows for something the frame cannot load: an unresolved `include::`, a relative image. It names the target.

**Error box**:
What replaces a diagram that failed to render: the message and the diagram source. The rest of the document still renders.

**Smetana**:
PlantUML's pure-Java layout engine, used because Graphviz's wasm build cannot run in the frame. Complex graphs can lay out differently from `dot`.

**Page limit**:
Orca's 10 MiB limit on the entry. `scripts/build.mjs` fails above 9.5 MiB.

**Release**:
A tagged, versioned build published as a GitHub release by the weekly workflow `.github/workflows/release.yml`. Only releases change `editor/index.html` on `main`.
