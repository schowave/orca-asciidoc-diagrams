# AsciiDoc Preview – PlantUML & Mermaid

An [Orca](https://github.com/stablyai/orca) plugin that renders AsciiDoc files (`.adoc`, `.asciidoc`, `.asc`) with inline PlantUML and Mermaid diagrams. It runs fully offline, inside Orca's plugin sandbox.

**Status:** early development. See [SPEC.md](SPEC.md).
