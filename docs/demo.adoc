= Online Shop – Architecture Overview
:toc: left

The shop lets customers browse products, place orders and track deliveries.

NOTE: All diagrams on this page render locally, inside Orca. Nothing leaves your machine.

== Context

.System context (C4)
[plantuml]
----
!include <C4/C4_Context>
Person(customer, "Customer", "Buys products online")
System(shop, "Online Shop", "Catalog, cart and checkout")
System_Ext(payment, "Payment Provider", "Card and wallet payments")
System_Ext(carrier, "Parcel Carrier", "Delivery and tracking")
Rel(customer, shop, "Browses and orders")
Rel(shop, payment, "Charges")
Rel(shop, carrier, "Books shipments")
----

== Checkout flow

[plantuml]
----
actor Customer
participant Shop
participant Payment
Customer -> Shop : Place order
Shop -> Payment : Authorize card
Payment --> Shop : Authorized
Shop --> Customer : Order confirmed
----

== Order states

[mermaid]
----
stateDiagram-v2
  [*] --> Placed
  Placed --> Paid : payment authorized
  Paid --> Shipped : parcel handed over
  Shipped --> Delivered
  Placed --> Cancelled
  Delivered --> [*]
----
