== API

[source,typescript]
----
export async function placeOrder(cart: Cart): Promise<Order> {
  const order = await orders.create({ items: cart.items, total: cart.total })
  await events.publish('order.placed', { id: order.id })
  return order
}
----

== Capacity

The shop must handle stem:[\lambda = 120] orders per minute at peak.
With an average service time stem:[S], one instance reaches utilization

[stem]
++++
\rho = \frac{\lambda \cdot S}{c}
++++

where stem:[c] is the number of instances, so we keep stem:[\rho < 0.7].
